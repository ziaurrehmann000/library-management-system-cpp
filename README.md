# 📚 Library Management System in C++

A console-based Library Management System developed in C++ to manage books, the library, and members.

This project demonstrates Object-Oriented Programming, STL vectors, file handling, searching, and basic library operations.

## 🚀 Features

- Add new books
- Display all books
- Search books by ID
- Add library members
- Display registered members
- Issue books
- Return books
- Track book availability
- Save book data to files
- Save member data to files
- Load saved data when the program starts
- Menu-driven console interface

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- STL `vector`
- File Handling
- `fstream`
- `sstream`
- Standard Input/Output
